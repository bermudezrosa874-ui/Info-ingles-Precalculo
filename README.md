# Analytical Geometry: Interactive Infographic

**Geometría Analítica: Infografía Interactiva**

Universidad Nacional Abierta y a Distancia (UNAD) · Precalculus / Precálculo

- **Author / Autora:** Rosalinda Bermudez Urbay
- **Tutor / Tutora:** Lizeth Melissa Sanches Casas
- **Delivery date / Fecha de entrega:** November 22, 2026 / 22 de noviembre de 2026

Interactive web infographic about the straight line, the circle, the ellipse and the hyperbola, with live graphs (JSXGraph), KaTeX formulas, worked examples, exercises, a self-assessment and APA 7 references. The site always opens in English and can be switched to Spanish (EN | ES).

## Stack

React + TypeScript (Vite), React Router (hash routes, static hosting friendly), JSXGraph, KaTeX, Lucide React, Vitest + Testing Library, Playwright.

## Run

```
npm install
npm run dev        # development
npm run build      # static site in dist/
npm test           # unit tests
npm run test:e2e   # integration / responsive tests (uses Google Chrome)
```
